## 🚀 How to Run Locally

Each project is completely self-contained and workable without requiring build tools or dependencies:

### Option 1: Direct File Open
Simply double-click `index.html` at the root, or enter any subfolder (`beginner/index.html`, `intermediate/index.html`, `advanced/index.html`) to launch directly in any modern web browser.

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Using Node.js:
```bash
npx serve .
```
Navigate to `http://localhost:8000/` to explore the **Master Hub**, or click directly into each level.

### 1. GitHub Pages
1. Push this repository to GitHub:
   ```bash

   git add .
   git commit -m "feat: complete ShadowFox frontend internship tasks"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```

2. In your repository on GitHub, navigate to **Settings > Pages**.
3. Under **Build and deployment > Source**, select **Deploy from a branch** and set Branch to `main` and folder to `/ (root)`.
